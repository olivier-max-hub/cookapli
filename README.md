# Cookapli

La suite d'outils de cuisine : de vraies recettes, avec ce que tu as.

- `index.html` : l'accueil. On y trouve le champ « J'ai… » et l'accès à tous les outils.
- `courses.html` : la liste de courses. On peut ajouter des articles à la main, depuis une recette, ou les recettes « presque prêtes ». Le bouton « Ranger les articles pris dans le frigo » les envoie dans Friscan.

## Liens avec les autres outils (même site : olivier-max-hub.github.io)
- **Friscan** (`../friscan/`) : réserves (frigo et placard), scanner, recettes possibles. `friscan/data.js` sert de référentiel d'ingrédients commun.
- **Mes recettes** (`../recettes/`) : la collection de recettes.
- Tous ces outils partagent le stockage local du téléphone :
  - `friscan.fridge` : les réserves ;
  - `friscan.placard` : le placard ;
  - `cookapli.courses` : la liste de courses ;
  - `cookapli.recettes` : le cache des recettes.

## Mettre en ligne
Settings, puis Pages, puis Branch `main` / `(root)`, puis Save. L'adresse est https://olivier-max-hub.github.io/cookapli/
